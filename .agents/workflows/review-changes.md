# Review changes

1. Inspect diff and relevant surrounding context.
2. Check correctness, security, compatibility, concurrency, resource limits, and error paths.
3. Verify changed-line mapping and evidence for every finding.
4. Check tests for positive, negative, and adversarial cases.
5. Report only actionable, nonduplicate, supported findings; otherwise say no verified findings.
6. State checks that were not run and uncertainty explicitly.
