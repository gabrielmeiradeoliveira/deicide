# Implement feature

1. Read `AGENTS.md` and relevant rules/skills.
2. Define acceptance criteria and the smallest complete vertical slice.
3. Identify touched contracts, trust boundaries, and affected tests.
4. Choose agents by task: implementer for code, test specialist for tests, security reviewer for risky changes. Parallelize only independent work.
5. Implement without scaffolding unrelated modules.
6. Run available targeted tests, lint, and type checks.
7. Summarize actual changes, executed commands, results, limitations, and follow-ups.
