# Module development

1. Confirm the problem and acceptance criteria before creating a module.
2. Reuse shared context, finding schema, budgeting, and validation.
3. Start with deterministic detection; add LLM investigation only when justified.
4. Require traceable evidence and valid source locations for findings.
5. Include negative cases and false-positive fixtures.
6. Keep module-specific code isolated from orchestration and transport.
